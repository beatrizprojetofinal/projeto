🎮 ReabiPlay – Plataforma Colaborativa de Jogos Sérios Aplicados à Reabilitação de Idosos

📌 Sobre o Projeto

O ReabiPlay é uma plataforma colaborativa desenvolvida no âmbito de um Projeto Final de Curso, com o objetivo de integrar ferramentas digitais no processo de reabilitação física e cognitiva de idosos.
A plataforma procura promover a interação e colaboração entre pacientes, profissionais de saúde e familiares, disponibilizando um conjunto de funcionalidades que permitem personalizar, acompanhar e incentivar o processo de reabilitação.
Através da utilização de jogos sérios (Serious Games), os pacientes podem realizar atividades adaptadas às suas necessidades e capacidades, enquanto os profissionais de saúde acompanham a sua evolução e ajustam os exercícios de acordo com o desempenho apresentado.
O projeto pretende contribuir para uma reabilitação mais acessível, interativa e motivadora, promovendo a autonomia, o bem-estar e a qualidade de vida da população idosa.

🎯 Objetivos

Desenvolver uma plataforma digital de apoio à reabilitação física e cognitiva de idosos.
Promover a colaboração entre pacientes, profissionais de saúde e familiares.
Disponibilizar jogos sérios personalizados e adaptados às necessidades de cada paciente.
Permitir o acompanhamento e a monitorização da evolução dos pacientes.
Incentivar a participação ativa através de mecanismos de motivação e recompensas.
Facilitar a comunicação e a partilha de experiências entre os diferentes utilizadores.

✨ Principais Funcionalidades

🎮 Jogos Sérios e Exercícios de Reabilitação

Jogos personalizados de acordo com as necessidades de cada paciente.
Exercícios de estimulação cognitiva, nomeadamente atividades de memória.
Diferentes níveis de dificuldade, adaptados às capacidades dos pacientes.

📊 Monitorização do Progresso

Acompanhamento do desempenho dos pacientes.
Consulta de estatísticas e resultados das atividades realizadas.
Monitorização da evolução ao longo do processo de reabilitação.
Possibilidade de os profissionais de saúde ajustarem as atividades de acordo com o progresso observado.

💬 Comunicação e Colaboração

Sistema de mensagens entre pacientes e profissionais de saúde.
Fóruns de discussão para partilha de experiências e apoio mútuo.
Envolvimento dos familiares no processo de acompanhamento.

🏆 Motivação e Recompensas

Feedback visual durante a realização das atividades.
Recompensas associadas ao desempenho.
Mecanismos de incentivo à participação e continuidade dos exercícios.

🧪 Testes e Validação

A plataforma foi submetida a testes em ambientes controlados e em contextos reais, permitindo avaliar a sua funcionalidade, usabilidade e impacto no processo de reabilitação.
Os resultados evidenciaram que a personalização das atividades e a utilização de mecanismos de feedback positivo contribuem para aumentar a motivação e a adesão dos pacientes, promovendo melhorias no desempenho físico e cognitivo.

🛠️ Tecnologias e Ferramentas Utilizadas

O desenvolvimento do ReabiPlay recorreu a diferentes tecnologias, organizadas de acordo com as suas responsabilidades na aplicação.

Backend
Java – Linguagem de programação utilizada na implementação da lógica de negócio.
JSP (JavaServer Pages) – Utilizado para a criação de páginas web dinâmicas.
JDBC (Java Database Connectivity) – Responsável pela comunicação entre a aplicação Java e a base de dados.

Frontend
HTML – Estruturação das páginas web.
CSS – Estilização e apresentação da interface gráfica.

Base de Dados
MySQL – Sistema de gestão de base de dados relacional utilizado para armazenar e gerir os dados da plataforma.

Ferramentas de Desenvolvimento
Eclipse – Ambiente de desenvolvimento para Java.
Visual Studio Code – Editor utilizado no desenvolvimento frontend.
MySQL Workbench – Ferramenta de modelação e gestão da base de dados.
Apache Tomcat – Servidor de aplicação para execução da aplicação Java/JSP.

🚀 Instalação e Execução

Para executar o projeto localmente, são necessários os seguintes componentes:
Java JDK.
Apache Tomcat.
MySQL Server.
MySQL Workbench (opcional, para gestão da base de dados).

🎓 Contexto Académico

Este projeto foi desenvolvido no âmbito do Projeto Final de Curso, tendo como principal finalidade a conceção e implementação de uma solução tecnológica de apoio à reabilitação física e cognitiva da população idosa.
O ReabiPlay representa uma abordagem à aplicação de tecnologias digitais e jogos sérios na área da saúde, procurando melhorar a experiência de reabilitação através da personalização, colaboração e motivação dos pacientes.
